Come funziona con l'hardware reale?

L'ESP32 esegue periodicamente una richiesta HTTP al tuo server Python/Node/PHP sull'endpoint /api/active-pins. Il server confronta le date attuali con il database e restituisce un JSON contenente esclusivamente l'array dei PIN validi. Quando un utente digita un codice sul tastierino, l'ESP32 lo verifica in memoria o invia una query immediata.
